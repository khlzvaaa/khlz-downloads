## Windows

Распакуйте ZIP в постоянную папку и один раз запустите **khlz.exe**. При первом запуске откроется инструкция с клавишами и изображением крестика. Закройте это окно крестиком: khlz продолжит работать в фоне со значком в трее рядом с часами. Открывать окно приложения для каждого действия не нужно.

Выделите файл в Проводнике и нажмите и отпустите **Shift — Convert**, **Alt — Tools** или **Ctrl — Actions**. Выберите действие в круглом меню возле курсора. Перетаскивать файл не требуется. Запасные сочетания: **Ctrl+Alt+1 / 2 / 3**. Повторно инструкция открывается из меню значка в трее; там же можно включить автозапуск и полностью завершить khlz.

Базовые изображения, текст, PDF и ZIP работают сразу. Аудио/видео требуют FFmpeg, офисные документы — LibreOffice. Отдельно устанавливать .NET не нужно. В меню Actions есть **«Отправить на телефон»**: в системном окне выберите **«Связь с телефоном» (Phone Link)** или подключённый телефон. На телефоне используется приложение **«Связь с Windows»**; устройства нужно заранее связать. Это Windows preview с неполным совпадением функций macOS и без подписи издателя.

[Инструкция Windows, компоненты и ограничения](WINDOWS.md)

**Удалить фон:** выделите изображение → **Ctrl → Actions → Удалить фон**. Программа создаст рядом отдельный PNG с прозрачностью, сохранив оригинал. Обработка локальная, модель входит в Windows-сборку.

В Windows доступны **редакторы фото и видео с предпросмотром**: выделение области мышью, настройки изображения, воспроизведение и выбор интервала видео. Результаты сохраняются отдельными копиями. Если Windows не воспроизводит кодек, кадры можно просматривать по шкале времени через FFmpeg.

## macOS: файловые инструменты под рукой

**Удалить фон:** начните перетаскивать изображение в Finder → нажмите **⌃ Control → Actions → Удалить фон**. Встроенный Vision создаст рядом отдельный PNG с прозрачным фоном; оригинал останется без изменений.

Начните перетаскивать файл в Finder и удерживайте клавишу. Вокруг указателя появится круглое меню — отпустите файл над нужной командой.

| Клавиша | Меню | Возможности |
| --- | --- | --- |
| **Shift** | Convert | Конвертация документов, таблиц, презентаций, изображений, PDF, аудио и видео |
| **⌘ Command** | Tools | Сжатие, изменение размера, обрезка, работа с PDF и медиа |
| **⌃ Control** | Actions | Копирование, перемещение, путь к файлу, AirDrop и полка Float |

Обработка выполняется локально. Приложение не загружает файлы на сервер. Оригиналы при конвертации сохраняются; результаты получают отдельные имена.

## Документы и таблицы

| Файлы | Основные варианты |
| --- | --- |
| TXT, MD | PDF, текст, Markdown, RTF, DOCX, ODT |
| DOC, DOCX, ODT, RTF | PDF, TXT, DOCX, ODT, RTF |
| PPT, PPTX, ODP | PDF, PPTX, ODP |
| XLS, XLSX, ODS, CSV, TSV | PDF, XLSX, ODS, CSV, TSV |
| PNG, JPEG, HEIC, TIFF, BMP, WebP, AVIF | Форматы изображений и PDF |
| PDF | TXT и изображения всех страниц |

Для офисных форматов установите дополнительные компоненты по кнопке ниже. TXT/MD → PDF, TXT и RTF работают без LibreOffice. В Command для этих файлов доступна команда **Export to PDF**.

PDF сохраняет статические слайды без анимации; CSV/TSV — только первый лист. Оформление Office зависит от установленных шрифтов. Документы с макросами, внешними связями и паролем отклоняются. PDF → DOCX пока не поддерживается.

## Установка

1. Скачайте ZIP по кнопке выше и распакуйте его.
2. Перенесите **khlz.app** в «Программы» и откройте.
3. При первом запуске появится инструкция с клавишами и изображением красного крестика. Закройте её крестиком слева вверху — khlz продолжит работать в фоне. Открывать окно приложения для работы с файлами не нужно.
4. Найдите значок khlz в строке меню. Через него доступны инструкция, настройки и полный выход.

Перед обновлением завершите предыдущую версию через меню khlz.

**Сборка пока не подписана сертификатом Developer ID и не прошла нотариальную проверку Apple. macOS может заблокировать запуск. Это тестовая версия, а не готовый стабильный выпуск.**

## Дополнительные возможности

[⬇ Установить дополнительные форматы](https://github.com/khlzvaaa/khlz-downloads/releases/download/v0.5.0/khlz-extra-formats.zip)

Нужны аудио, видео, WebP, AVIF или PDF/A? Скачайте отдельный установщик, распакуйте ZIP и откройте **Install-Extra-Formats.command**. Он покажет список компонентов и установит их после ввода `INSTALL`. Основное приложение остаётся без изменений.

Устанавливаются FFmpeg/ffprobe, WebP, libheif с плагинами и LibreOffice для офисных форматов и PDF/A через Homebrew. Нужны интернет и несколько гигабайт места. **Если Homebrew ещё нет, сначала установите его с открывшегося официального сайта, затем повторно запустите установщик.** Дополнительные системные инструменты и права администратора могут потребоваться при установке Homebrew или LibreOffice.

[Подробная инструкция и ручная установка](EXTRA-FORMATS.md) · [Посмотреть код установщика](Install-Extra-Formats.command)

После установки завершите khlz через меню и откройте снова. Это онлайн-установщик зависимостей; сами кодеки не входят в ZIP. Установка добавляет форматы, уже поддерживаемые khlz. Базовые операции с изображениями и PDF работают на системных библиотеках macOS.

## Что ещё дорабатывается

SVG, электронные книги, Apple Pages/Numbers/Keynote и OCR пока не поддерживаются. Редакторы упрощены; сжатие PDF растрирует страницы и удаляет интерактивные элементы.

Поддержка Intel в этом выпуске отсутствует. Сертификат Apple не заменяет проверку качества приложения.
