## Файловые инструменты под рукой

Начните перетаскивать файл в Finder и удерживайте клавишу. Вокруг указателя появится круглое меню — отпустите файл над нужной командой.

| Клавиша | Меню | Возможности |
| --- | --- | --- |
| **Shift** | Convert | Конвертация изображений, PDF, аудио и видео |
| **⌘ Command** | Tools | Сжатие, изменение размера, обрезка, работа с PDF и медиа |
| **⌃ Control** | Actions | Копирование, перемещение, путь к файлу, AirDrop и полка Float |

Обработка выполняется локально. Приложение не загружает файлы на сервер. Оригиналы при конвертации сохраняются; результаты получают отдельные имена.

## Установка

1. Скачайте ZIP по кнопке выше и распакуйте его.
2. Перенесите **khlz.app** в «Программы» и откройте.
3. Найдите значок khlz в строке меню. Через него доступны настройки и выход.

Перед обновлением завершите предыдущую версию через меню khlz.

**Сборка пока не подписана сертификатом Developer ID и не прошла нотариальную проверку Apple. macOS может заблокировать запуск. Это тестовая версия, а не готовый стабильный выпуск.**

## Дополнительные возможности

Для аудио и видео требуются отдельно установленные FFmpeg и ffprobe; для WebP — cwebp; для программного экспорта AVIF — heif-enc; для PDF/A — LibreOffice. Эти программы не входят в архив и не устанавливаются автоматически. Базовые операции с изображениями и PDF используют системные библиотеки macOS.

## Что ещё дорабатывается

Офисные форматы, SVG, электронные книги и OCR не поддерживаются. Редакторы упрощены; сжатие PDF растрирует страницы и удаляет интерактивные элементы.

Поддержка Intel в этом выпуске отсутствует. Сертификат Apple не заменяет проверку качества приложения.
