# khlz для Windows · 0.6.2 preview

Windows 10 (2004 и новее) / Windows 11, x64. На Windows ARM64 приложение запускается через эмуляцию x64 Windows 11; отдельная ARM64-сборка пока не выпускается.

Распакуйте ZIP в постоянную папку и запустите khlz.exe один раз. Устанавливать .NET отдельно не нужно. При первом запуске откроется инструкция. Закройте её крестиком справа вверху: приложение продолжит работать в фоне, со значком в трее рядом с часами. Значок может скрываться под стрелкой ↑. Повторно инструкция открывается из меню значка.

## Работа с файлами

1. Выделите файл или несколько файлов в Проводнике.
2. Нажмите и отпустите **Shift** для конвертации, **Alt** для инструментов, **Ctrl** для действий.
3. Выберите операцию в круглом меню возле курсора. Перетаскивать файл или открывать окно khlz не требуется.

Нажимайте клавишу отдельно, без мыши и других клавиш. Обычные Ctrl+C, Ctrl+клик и Shift+стрелка должны оставаться действиями Проводника. Альтернативные сочетания: **Ctrl+Alt+1**, **Ctrl+Alt+2**, **Ctrl+Alt+3**. Одиночные клавиши можно отключить в настройках. Esc закрывает меню, Tab и Enter позволяют выбрать действие с клавиатуры. Если операций много, используйте стрелки ‹ › в центре круга или Page Up / Page Down.

Результаты конвертации сохраняются рядом с оригиналом под новым именем. «Переместить» в Actions отдельно спрашивает папку и подтверждение. Меню Actions также содержит копирование, пути в буфер обмена, PowerShell, Проводник и плавающую полку с drag-and-drop. Автозапуск можно включить в инструкции или настройках. Для полного выхода выберите «Завершить khlz» в трее.

## Удалить фон

Выделите одно или несколько изображений в Проводнике → **Ctrl → Actions → Удалить фон**. Рядом с каждым оригиналом появится отдельный **PNG с прозрачным фоном** (`имя-no-background.png`). Исходный файл и уже созданные копии не перезаписываются; размер холста сохраняется.

Обработка выполняется локально. Модель удаления фона включена в программу: Python, интернет и Copilot+ не требуются. Для чтения HEIC/AVIF/WebP может понадобиться установленный FFmpeg. На сложных изображениях с волосами, стеклом или похожим по цвету фоном качество автоматического выделения может различаться.

## Редакторы с предпросмотром

В **Alt → Tools** инструменты фото и видео открываются в отдельном редакторе. Слева показан файл, справа — параметры. Закрытие редактора возвращает khlz в фоновый режим; оригинал не меняется, сохранение создаёт копию.

- **Фото:** обрезка и скрытие области мышью, размер с сохранением пропорций или отдельной высотой, яркость/контраст/насыщенность, подпись с выбором положения и размера, белая рамка и качество JPEG. Предпросмотр обновляется при изменении параметров; есть сравнение с оригиналом. Для обрезки можно отдельно показать результат.
- **Видео:** воспроизведение/пауза, переход к кадру по шкале, выбор начала и конца интервала, обрезка или скрытие области мышью, скорость, снимок кадра и удаление звука. Выделение области пересчитывается в пиксели исходного файла. При скрытии области можно задать временной интервал.
- **Несколько файлов:** список сверху переключает предпросмотр. Область сохраняется в относительных координатах и применяется пропорционально к каждому файлу.

Воспроизведение видео зависит от системных кодеков Windows. Если кодек не поддерживается, остаётся просмотр кадров по шкале через FFmpeg. Степень сжатия видео применяется при сохранении, в редакторе показывается исходное видео. Аудио- и PDF-инструменты пока используют отдельные окна параметров.

## Отправить на телефон

Выделите файлы в Проводнике, нажмите **Ctrl** и выберите **«Отправить на телефон»**. В системном окне обмена выберите **«Связь с телефоном» (Phone Link)** или название подключённого телефона. Получение обрабатывает приложение **«Связь с Windows»** на телефоне.

Телефон нужно заранее связать с компьютером через эти приложения. Если получателя нет в системном окне, khlz показывает пояснение и ссылку на [инструкцию Microsoft](https://support.microsoft.com/windows/apps/phonelink/seamlessly-transfer-content-between-your-devices). Доступность передачи зависит от версии Windows, приложений и телефона. Получатель выбирается в системном окне; khlz не отправляет файлы без этого выбора.

## Компоненты

Сразу работают PNG/JPEG/BMP/TIFF, изменение размера, обрезка, подпись, скрытие области, яркость/контраст, белая рамка, коллаж, чтение QR, создание PDF, объединение/разделение/порядок страниц PDF, PDF → изображения, TXT/MD → PDF/TXT/MD/RTF и распаковка ZIP.

Для аудио, видео, WebP, AVIF и HEIC установите FFmpeg. Поддержка конкретного кодека зависит от установленной сборки. Для DOCX/ODT/RTF, PPTX/ODP, XLSX/ODS/CSV/TSV и PDF/A установите LibreOffice. Можно использовать официальные установщики или Windows Package Manager:

```powershell
winget install --id Gyan.FFmpeg --exact
winget install --id TheDocumentFoundation.LibreOffice --exact
```

Это ручные команды установки; khlz ничего не скачивает автоматически. После установки перезапустите приложение. Компоненты ищутся в PATH, WinGet Links, tools рядом с khlz.exe и стандартной папке LibreOffice.

## Ограничения предварительной версии

Это отдельная реализация Windows, функциональное совпадение с macOS неполное. Вместо Command используется Alt; вместо AirDrop — «Отправить на телефон» через Phone Link в системном окне Windows. Перенос папок между дисками не поддерживается. GIF/SVG, старые бинарные DOC/PPT/XLS, OCR и PDF → TXT пока не поддерживаются. Редакторы фото и видео поддерживают одну область выделения; несколько масок и монтаж дорожек отсутствуют. При объединении видео исходные параметры потоков должны быть совместимы. Разделение видео происходит по ключевым кадрам. Сжатие не гарантирует уменьшение размера.

Текст в PDF сохраняется как изображение, Markdown — как исходный текст; поиск и копирование текста в таком PDF недоступны. Сжатие PDF растрирует страницы и удаляет формы, ссылки и выделяемый текст. CSV/TSV сохраняет первый лист. PDF/A экспортируется LibreOffice как PDF/A-2b, внешний валидатор соответствия не запускается. Макросы, внешние связи и вложения в офисных документах отклоняются. Архивы со ссылками и небезопасными путями не распаковываются.

Ограничения обработки: до 64 файлов / 1 ГБ входных данных, 40 Мп на изображение, 500 страниц PDF, 4 ГБ готовых результатов, 5 минут на задание. Внешние обработчики выполняются с правами пользователя; отдельного AppContainer нет. Во время обработки внешнего файла временный размер результатов контролируется не непрерывно.

Сборка пока без подписи издателя: Windows SmartScreen может показать предупреждение. Исходники и автоматические проверки — в основном репозитории проекта.

## Разработка

На Windows с .NET SDK 10 и FFmpeg/ffprobe:

```powershell
dotnet run --project windows/Khlz.Windows.Checks -c Release
dotnet publish windows/Khlz.Windows -c Release -r win-x64 --self-contained true -o dist/windows
$env:KHLZ_BACKGROUND_TEST_IMAGE = (Resolve-Path test-assets/foreground-portrait.png).Path
dist/windows/khlz.exe --smoke-test
```

CI проверяет реальные изображения и PDF, сохранность оригиналов, конфликты имён, распаковку, обработку клавиш и запуск окон/трея. Выделение файлов в пользовательском Проводнике, разные мониторы/DPI и конфликтующие сторонние горячие клавиши требуют ручной проверки на целевом ПК.
